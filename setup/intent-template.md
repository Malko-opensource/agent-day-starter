# intent: 내 개인비서

이 파일을 프로젝트 폴더에 `intent.md` 로 복사해서 채웁니다. 기술 용어 없이 내 말로 씁니다. 빈칸을 다 채울 필요는 없습니다.

## 덜고 싶은 일

지금 어떤 일에 시간을 쓰고 있나요. 언제, 얼마나 걸리나요. 무엇을 자주 놓치나요.

## 바라는 결과

비서가 생기면 무엇이 달라져 있으면 좋겠나요. 두세 줄이면 됩니다.

## 맡길 일 (일곱 가지 중에서 고른다)

클로드가 할 수 있는 일을 일곱 가지로 나눴습니다. 내 업무에 있는 칸만 쓰고 나머지는 "없음" 으로 둡니다. 두세 칸만 채워도 비서 하나가 나옵니다.

| 일 | 이런 일입니다 | 내 업무에서는 | 바라는 결과 |
| --- | --- | --- | --- |
| 조사 | 웹에서 찾아 읽고 출처와 함께 남긴다 | | |
| 분석 | 모아 둔 자료를 읽고 쏠림, 빠진 것, 우선순위를 본다 | | |
| 코딩 | 비서에 화면과 도구를 붙이고 고친다 | | |
| 문서쓰기 | 모은 내용을 보고서, 메일, 메시지 초안으로 쓴다 | | |
| 정리 | 흩어진 메모를 항목으로 나누고 묶는다 | | |
| 알림 | 챙길 때가 된 것을 내가 정한 곳으로 알려 준다 | | |
| 예약 | 정해 둔 시각에 위의 일을 미리 돌려 둔다 | | |

## 지켜야 할 것

- 화면에 생기는 기능은 클로드가 도구로도 쓸 수 있어야 한다.
- (회사 자료 기준: 강사가 불러 주는 문장을 여기에 그대로 적습니다. 오늘 실습에서는 실명 대신 "김 대리", "A 프로젝트" 처럼 바꿔 씁니다.)
