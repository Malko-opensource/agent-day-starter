# 용어 한 장

오늘 클로드의 답에 자주 나오는 말입니다. 모르는 말이 나오면 여기부터 봅니다. 여기 없는 말은 클로드에게 "방금 그 말을 쉽게 풀어 줘" 라고 하면 됩니다.

| 말 | 뜻 |
| --- | --- |
| 서버 | 비서를 띄우는 프로그램. `node server.js` 를 넣은 터미널 창 하나를 차지한다. 그 창을 닫으면 비서 화면이 꺼지고, 자료는 남는다 |
| 포트 | 주소 끝의 숫자. `http://localhost:4321` 의 4321 |
| 터미널 | 명령을 글자로 넣는 창. 오늘은 두 개를 쓴다. 하나는 서버, 하나는 클로드 |
| 세션 | 클로드와의 대화 한 번. 새로 켠 세션은 앞의 대화를 기억하지 못한다 |
| 도구 | 클로드가 비서에 시킬 수 있는 기능 하나. 화면 위쪽의 "도구 N개" 가 그 개수다 |
| 스킬 | 클로드에게 일하는 순서를 적어 준 문서. `/이름` 으로 부른다 |
| 명세서 | 무엇을 만들지 적은 문서. 오늘은 `_final-contract.md` 한 장만 본다 |
| 테스트 | 자동으로 돌리는 확인 목록. `npm test` 로 돌린다. "N개 통과" 가 나오면 된 것이다 |
| 커밋 | 지금 상태를 되돌릴 수 있게 찍어 두는 것. 파일 저장과는 다르다. 파일은 이미 저장돼 있다 |
| 토큰 | 클로드가 읽고 쓰는 글자의 단위. 사용량이 이걸로 잡힌다 |
| Plan 모드 | 계획만 세우고 파일은 바꾸지 않는 상태. `Shift+Tab` 으로 드나든다 |
| P0, P1, P2 | 디자인 점검에서 나온 문제의 급한 정도. P0 은 바로 막는 문제, P1 은 고쳐야 할 문제, P2 는 나중에 |
| `A-001`, `R-003` 같은 기호 | 클로드가 인터뷰하며 붙인 메모 번호. 몰라도 된다 |

## 자주 헷갈리는 것

- **끝났는지 모르겠을 때:** 클로드의 답 맨 끝 두 줄(`끝났나`, `지금 할 일`)을 봅니다. 클로드가 마지막에 "더 할까요?" 라고 물어도 답하지 않아도 됩니다. "아니, 여기까지" 라고 하면 됩니다.
- **서버를 껐다 켜라고 할 때:** 클로드 창이 아니라 `node server.js` 를 넣은 창에서 합니다. `Ctrl+C` 를 누르고 `node server.js` 를 다시 넣습니다.
- **답이 길 때:** "세 줄로 줄여 줘" 라고 합니다.
- **새로 켠 클로드에게 "방금 그거" 가 안 통할 때:** 새 세션은 앞의 대화를 모릅니다. 화면 이름과 파일 이름으로 말합니다.
